RISHITA.EXE — ANNIVERSARY WEBSITE

QUICK DEPLOY USING GITHUB PAGES (FREE)
1. Sign in to GitHub and create a NEW PUBLIC repository named rishita-anniversary (or any name you like).
2. Choose Add file -> Upload files.
3. Upload index.html from this folder (or drag index.html from the ZIP into GitHub's upload page).
4. Commit the upload.
5. Open repository Settings -> Pages.
6. Under Build and deployment, choose Deploy from a branch.
7. Choose branch main and folder /(root), then Save.
8. Wait a minute or two. The Pages section will show the published URL, usually https://YOUR-USERNAME.github.io/rishita-anniversary/ .
9. Open that URL in a private/incognito window and test it on mobile.
10. Send the URL to Rishita on WhatsApp.

PRIVACY
A public GitHub Pages site is accessible to anyone who has the URL (and potentially discoverable). Do not upload raw WhatsApp exports, private screenshots, or details she would not want public. This page contains only a curated summary and can be edited before publishing.

CUSTOMIZE
Open index.html in a text editor. Search for "Happy anniversary, meri chaos machine" or other text and edit it. Save and upload the updated index.html to the same repository.
